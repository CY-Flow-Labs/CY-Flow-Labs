## Featured project

### [CNC Route Studio](https://github.com/CY-Flow-Labs/cnc-route-studio)

An offline-first, Fanuc-style 3+1-axis CNC route simulator and program preflight tool.

離線優先的 Fanuc 類 3+1 軸 CNC 刀路模擬與程式預檢工具。

- Compare two NC programs with dual-color 3D toolpaths
- Inspect coordinate systems, tool offsets, macros, stock and fixtures
- Flag travel, rapid-entry and collision risks before machine-side verification
- Process imported NC programs locally in the browser

[View source and setup guide →](https://github.com/CY-Flow-Labs/cnc-route-studio)
